# คู่มือการใช้งานแอปพลิเคชัน Calories Guard

คู่มือนี้สำหรับผู้ใช้ทั่วไปที่ต้องการใช้แอป Calories Guard เพื่อบันทึกอาหาร ติดตามแคลอรี่ ดูสารอาหาร ดูความคืบหน้า และใช้ผู้ช่วย AI ด้านโภชนาการ

## 1. เริ่มต้นใช้งาน

### 1.1 เปิดแอป

ผู้ใช้สามารถเข้าใช้งานได้ 2 ช่องทาง

- Android APK: ติดตั้งไฟล์ APK ที่ทีมพัฒนาแจกให้
- Web/PWA: เปิด `https://app.caloriesguard.com`

### 1.1.1 ความต้องการขั้นต่ำ

| ช่องทาง | ความต้องการ |
|---|---|
| Android APK | Android ที่ติดตั้ง APK ภายนอกได้ และมีอินเทอร์เน็ต |
| Web/PWA | Chrome, Edge, Safari หรือ browser สมัยใหม่ |
| Health Connect | Android ที่ติดตั้ง Health Connect และให้สิทธิ์อ่านข้อมูลสุขภาพ |
| อีเมล | ต้องเข้าถึง inbox ได้เพื่อรับรหัสยืนยันจาก Supabase |

### 1.1.2 การติดตั้ง APK บน Android

1. เปิดไฟล์ `app-debug.apk` หรือไฟล์ APK ที่ทีมแจก
2. ถ้าเครื่องถามสิทธิ์ติดตั้งจากแหล่งที่ไม่รู้จัก ให้เปิดอนุญาตเฉพาะแอปที่ใช้ติดตั้ง
3. ติดตั้งแอป
4. เปิด Calories Guard
5. ถ้าแอปค้างที่หน้า config missing ให้แจ้งทีมพัฒนา เพราะ build นั้นไม่ได้ใส่ `SUPABASE_ANON_KEY`

### 1.1.3 การติดตั้งเป็น PWA

บน Chrome/Edge:

1. เปิด `https://app.caloriesguard.com`
2. กดเมนู browser
3. เลือก Install app หรือ Add to Home Screen
4. เปิดจากไอคอน Calories Guard ที่หน้า home/desktop

### 1.2 สมัครสมาชิก

1. เปิดหน้าแรกของแอป
2. กด `สมัครสมาชิก`
3. กรอกชื่อ นามสกุล อีเมล รหัสผ่าน และยืนยันรหัสผ่าน
4. กด `Done`
5. ตรวจอีเมลเพื่อรับรหัสยืนยันจาก Supabase
6. กรอกรหัส OTP 6 หลักในหน้า `ยืนยันอีเมล`

เงื่อนไขรหัสผ่านในหน้าสมัคร:

- ความยาวอย่างน้อย 8 ตัวอักษร
- มีตัวพิมพ์ใหญ่ A-Z อย่างน้อย 1 ตัว
- มีอักขระพิเศษอย่างน้อย 1 ตัว

ถ้าเห็นข้อความว่าอีเมลยังไม่ได้ยืนยัน ให้กดเข้าสู่ระบบอีกครั้ง แอปจะพาไปหน้า verify และส่งรหัส Supabase ใหม่ให้

### 1.3 เข้าสู่ระบบ

1. กด `เข้าสู่ระบบ`
2. กรอกอีเมลและรหัสผ่าน
3. กดปุ่มเข้าสู่ระบบ
4. ถ้าเป็นผู้ใช้ใหม่ ระบบจะพาไปทำ onboarding ต่อ

### 1.4 ลืมรหัสผ่าน

1. ไปหน้าเข้าสู่ระบบ
2. กด `ลืมรหัสผ่าน?`
3. กรอกอีเมลที่ใช้สมัคร
4. ตรวจอีเมล reset password
5. ตั้งรหัสผ่านใหม่
6. กลับมา login อีกครั้ง

ข้อควรระวัง:

- ใช้อีเมลเดียวกับที่สมัครไว้
- ถ้าไม่ได้อีเมล ให้ตรวจ spam/junk
- ถ้า link หมดอายุ ให้ขอ reset ใหม่

## 2. ตั้งค่าโปรไฟล์ครั้งแรก

หลังสมัครและยืนยันอีเมล แอปจะถามข้อมูลพื้นฐานเพื่อใช้คำนวณเป้าหมายสุขภาพ

ลำดับ onboarding โดยรวม:

1. ยืนยันอีเมล
2. เลือกเพศ
3. กรอกวันเกิด ส่วนสูง น้ำหนัก
4. เลือกระดับกิจกรรม
5. เลือกเป้าหมาย
6. ตั้งน้ำหนักเป้าหมาย
7. ตั้งระยะเวลา
8. ตั้งค่าการแพ้อาหาร ถ้ามี
9. เข้าหน้าหลัก

### 2.1 เลือกเพศ

เลือกเพศตามข้อมูลสุขภาพที่ต้องการใช้คำนวณ BMR/TDEE

### 2.2 กรอกข้อมูลส่วนตัว

กรอกข้อมูลต่อไปนี้

- วันเกิด
- ส่วนสูง
- น้ำหนักปัจจุบัน

ระบบใช้ข้อมูลนี้เพื่อคำนวณ BMI และเป้าหมายพลังงานต่อวัน

คำแนะนำ:

- วันเกิดมีผลกับ BMR/TDEE
- ส่วนสูงและน้ำหนักควรกรอกตามค่าปัจจุบัน
- ถ้ากรอกผิด สามารถแก้ภายหลังได้ที่โปรไฟล์

### 2.3 เลือกระดับกิจกรรม

เลือกระดับกิจกรรมที่ใกล้เคียงกับชีวิตประจำวัน เช่น นั่งทำงานเป็นหลัก ออกกำลังกายเบา ปานกลาง หรือมาก

### 2.4 เลือกเป้าหมาย

ตัวอย่างเป้าหมาย:

- ลดน้ำหนัก
- รักษาน้ำหนัก
- เพิ่มกล้ามเนื้อ

### 2.5 ตั้งค่าน้ำหนักเป้าหมายและระยะเวลา

เลือกน้ำหนักเป้าหมายและระยะเวลาที่เหมาะสม ระบบจะช่วยคำนวณเป้าหมายแคลอรี่ต่อวันและสารอาหารหลัก

แนวทางความปลอดภัย:

- หลีกเลี่ยงเป้าหมายลดน้ำหนักเร็วเกินไป
- ถ้ามีโรคประจำตัว ตั้งครรภ์ หรือมีข้อจำกัดด้านโภชนาการ ควรปรึกษาผู้เชี่ยวชาญ
- ระบบเป็นตัวช่วยติดตาม ไม่ใช่คำวินิจฉัยทางการแพทย์

## 3. หน้าแรก

หน้าแรกใช้ดูภาพรวมของวันนี้

ข้อมูลหลักที่แสดง:

- แคลอรี่ที่ทานวันนี้
- เป้าหมายแคลอรี่
- โปรตีน คาร์บ ไขมัน
- น้ำหนักและ BMI
- มื้ออาหารวันนี้
- ปุ่มไปหน้าบันทึกอาหาร
- ปุ่มค้นหาร้านอาหารใกล้คุณ

ถ้าวันนี้ยังไม่ได้บันทึกอาหาร หน้าแรกจะแนะนำให้เริ่มบันทึกมื้อแรก

### 3.1 การเปลี่ยนวันที่

1. กดปุ่ม `เปลี่ยนวันที่`
2. เลือกวันที่ที่ต้องการดู
3. หน้าแรกจะแสดงสรุปอาหาร น้ำหนัก และมื้ออาหารของวันนั้น

ใช้เมื่อต้องการตรวจย้อนหลังหรือบันทึกย้อนหลัง

### 3.2 วงแหวนแคลอรี่

วงแหวนแสดงความคืบหน้าระหว่าง:

- แคลอรี่ที่กินแล้ว
- เป้าหมายแคลอรี่ต่อวัน

ถ้าเกินเป้าหมาย แอปอาจแสดงคำเตือนเพื่อให้ผู้ใช้ระวังมื้อต่อไป

### 3.3 การดู BMI

หน้าแรกแสดง BMI และหมวดหมู่ตามเกณฑ์เอเชีย ผู้ใช้สามารถกดดูรายละเอียดเพื่อเข้าใจช่วงน้ำหนักของตนเอง

## 4. บันทึกอาหาร

เข้าได้จากแถบนำทางล่าง ปุ่ม `บันทึก`

### 4.1 เพิ่มอาหารจากฐานข้อมูล

1. เลือกมื้อ เช่น มื้อเช้า มื้อกลางวัน มื้อเย็น หรือของว่าง
2. กดเพิ่มอาหาร
3. ค้นหาชื่อเมนู
4. เลือกรายการอาหาร
5. ปรับจำนวนหรือหน่วยเสิร์ฟ
6. กดเพิ่ม

ระบบจะรวมแคลอรี่และสารอาหารเข้ากับมื้ออาหารของวันนั้น

รายการมื้อหลักที่ใช้ในแอป:

- มื้อเช้า
- มื้อกลางวัน
- มื้อเย็น
- ของว่าง

หลังบันทึก ระบบจะอัปเดต:

- แคลอรี่รวม
- โปรตีนรวม
- คาร์บรวม
- ไขมันรวม
- รายการอาหารในหน้าแรก

### 4.2 เพิ่มเมนูอาหารด่วน

ใช้เมื่อไม่มีเมนูในฐานข้อมูล

1. เลือก `เพิ่มเมนูอาหารด่วน`
2. กรอกชื่อเมนูและข้อมูลโภชนาการเท่าที่ทราบ
3. กด `เพิ่ม + ส่งให้ Admin`

รายการนี้จะถูกส่งให้แอดมินตรวจสอบก่อนเพิ่มเข้า catalog หลัก

ควรกรอกให้ชัดเจนที่สุด เช่น:

- ชื่อเมนู: `ข้าวกะเพราไก่ไข่ดาว`
- ปริมาณ: 1 จาน
- แคลอรี่โดยประมาณ
- โปรตีน/คาร์บ/ไขมัน ถ้าทราบ

ถ้าข้อมูลไม่พอ แอดมินอาจปฏิเสธหรือปรับข้อมูลก่อนอนุมัติ

### 4.3 บันทึกน้ำ

ในหน้าบันทึกอาหารมีส่วน `ดื่มน้ำวันนี้` ให้เพิ่มจำนวนแก้วน้ำที่ดื่มในวันนั้น

### 4.4 บันทึกกิจกรรม

1. ไปที่ส่วน `กิจกรรมวันนี้`
2. กด `เพิ่มกิจกรรม`
3. เลือกประเภทกิจกรรม หรือกำหนดเอง
4. ใส่ระยะเวลา
5. ระบบคำนวณแคลอรี่ที่เผาผลาญโดยประมาณ
6. กดบันทึกกิจกรรม

### 4.5 ซิงค์ Samsung Health / Health Connect

ถ้าใช้อุปกรณ์ Android ที่รองรับ Health Connect สามารถกดซิงค์เพื่อดึงข้อมูลกิจกรรมได้

ถ้าขึ้นว่าไม่ได้รับสิทธิ์ ให้เปิด:

`Health Connect -> Apps -> Calories Guard -> อนุญาตการอ่านทั้งหมด`

ถ้ายังซิงค์ไม่ได้:

- ตรวจว่า Health Connect ติดตั้งแล้ว
- ตรวจว่าแอปสุขภาพต้นทาง เช่น Samsung Health เขียนข้อมูลเข้า Health Connect
- ปิดเปิดแอปใหม่
- ให้สิทธิ์ใหม่อีกครั้ง

## 5. อาหารแนะนำ

เข้าได้จากแถบนำทางล่าง ปุ่ม `อาหาร`

หน้านี้ใช้ดูอาหารที่เหมาะกับเป้าหมายและสารอาหารที่เหลือในวันนั้น เช่น อาหารโปรตีนสูง หรือเมนูที่ยังไม่เกินแคลอรี่

แนวทางใช้งาน:

1. ดูพลังงานและสารอาหารที่เหลือในวันนั้น
2. เลือกเมนูที่เหมาะกับเป้าหมาย
3. เปิดรายละเอียดสูตรหรือข้อมูลอาหาร
4. บันทึกเป็นมื้ออาหารหากต้องการ

ถ้าเลือกภูมิภาคในโปรไฟล์แล้ว ชื่ออาหารบางรายการอาจแสดงตามชื่อท้องถิ่นที่แอดมินอนุมัติ

## 5.1 แนะนำการออกกำลังกาย

เข้าได้จากแถบนำทางล่าง ปุ่ม `แดชบอร์ด`

หน้าดังกล่าวใช้ดูคำแนะนำด้านการออกกำลังกายและภาพรวมสุขภาพตามข้อมูลผู้ใช้ เช่น แคลอรี่ที่เหลือ เป้าหมาย และกิจกรรมที่เหมาะสม

## 6. ผู้ช่วย AI

กดปุ่ม floating chat รูปผู้ช่วยเพื่อเข้าสู่หน้าแชต

ใช้ถามเรื่อง:

- คำแนะนำโภชนาการ
- แคลอรี่โดยประมาณของอาหาร
- การวางแผนมื้ออาหาร
- วิธีใช้งานฟีเจอร์ในแอป

ข้อจำกัด:

- AI เป็นผู้ช่วยด้านโภชนาการ ไม่ใช่แพทย์
- คำตอบเป็นคำแนะนำเบื้องต้น ควรปรึกษาผู้เชี่ยวชาญเมื่อมีโรคประจำตัวหรือภาวะเฉพาะ
- ไม่ควรส่งข้อมูลอ่อนไหว เช่น เลขบัตรประชาชน รหัสผ่าน หรือข้อมูลการแพทย์ละเอียด
- ถ้า AI ตอบไม่ตรง ให้ถามใหม่โดยระบุบริบท เช่น ปริมาณอาหาร น้ำหนักตัว หรือเป้าหมาย

ตัวอย่างคำถาม:

- `ข้าวมันไก่ 1 จานประมาณกี่ kcal`
- `วันนี้เหลือแคลอรี่ 500 kcal กินอะไรดี`
- `อยากลดน้ำหนักแต่ยังได้โปรตีนพอ ควรกินอะไร`
- `วิธีบันทึกอาหารใหม่ทำอย่างไร`

## 6.1 AI ประมาณแคลอรี่จากข้อความ

บางหน้าจอมี sheet สำหรับให้ AI วิเคราะห์มื้ออาหารจากข้อความ ผู้ใช้สามารถพิมพ์รายการอาหาร เช่น:

`ข้าวสวย 1 ทัพพี ไข่เจียว 1 ฟอง ต้มจืด 1 ถ้วย`

ระบบจะประมาณรายการอาหารและแคลอรี่รวม จากนั้นผู้ใช้ตรวจสอบก่อนบันทึก

## 7. โปรไฟล์และการตั้งค่า

กดไอคอนโปรไฟล์ด้านขวาบน

สิ่งที่ทำได้:

- ดูข้อมูลส่วนตัว
- แก้ไขโปรไฟล์
- แก้ไขเป้าหมาย
- ดูความคืบหน้า
- ตั้งค่าหน่วย
- ตั้งค่าการแพ้อาหาร
- เปิดหน้าบทความ
- ดูเกี่ยวกับแอป
- ออกจากระบบ

### 7.1 แก้ไขโปรไฟล์

ใช้เมื่อต้องการแก้:

- ชื่อ
- รูปโปรไฟล์
- ส่วนสูง
- น้ำหนัก
- ข้อมูลพื้นฐานที่ใช้คำนวณเป้าหมาย

### 7.2 ตั้งค่าหน่วย

ผู้ใช้สามารถตั้งค่าหน่วยที่ต้องการแสดง เช่น น้ำหนัก ส่วนสูง น้ำ หรือพลังงาน ตามที่แอปรองรับ

### 7.3 ตั้งค่าภูมิภาคชื่ออาหาร

เลือกภูมิภาคเพื่อให้ระบบแสดงชื่ออาหารท้องถิ่น เช่น ภาคเหนือ ภาคอีสาน ภาคใต้ หรือภาคกลาง ถ้ามีข้อมูลที่แอดมินอนุมัติแล้ว

### 7.4 ลบบัญชี

ถ้าแอปเปิดให้ลบบัญชี ให้ผู้ใช้ตรวจสอบผลกระทบก่อนยืนยัน เพราะข้อมูลบางส่วนอาจถูก soft delete และไม่แสดงในระบบหลังจากนั้น

## 8. การแจ้งเตือน

แอปมีระบบแจ้งเตือน เช่น:

- แจ้งเตือนมื้ออาหาร
- แจ้งเตือนดื่มน้ำ
- แจ้งเตือนสรุปรายวัน
- แจ้งเตือน streak หรือ achievement
- แจ้งเตือนเมื่อแคลอรี่ใกล้หรือเกินเป้าหมาย

ผู้ใช้ควรเปิด permission การแจ้งเตือนในระบบปฏิบัติการเพื่อให้ทำงานครบ

## 9. ข้อมูลและความเป็นส่วนตัว

ข้อมูลที่แอปใช้:

- อีเมลและข้อมูลบัญชี
- ข้อมูลสุขภาพที่ผู้ใช้กรอก เช่น ส่วนสูง น้ำหนัก วันเกิด
- รายการอาหาร น้ำ กิจกรรม และน้ำหนัก
- รูปภาพอาหารหรือรูปโปรไฟล์ที่อัปโหลด

แนวทางใช้งานอย่างปลอดภัย:

- ใช้รหัสผ่านที่เดาได้ยาก
- ไม่ส่งรหัส OTP ให้ผู้อื่น
- ออกจากระบบเมื่อใช้เครื่องสาธารณะ
- แจ้งผู้ดูแลถ้าพบข้อมูลผิดปกติ

## 10. Troubleshooting

| อาการ | วิธีแก้ |
|---|---|
| สมัครแล้วไม่ได้อีเมล | ตรวจ spam/junk แล้วกดส่งรหัสใหม่ |
| Login แล้วขึ้น email not confirmed | กลับไปหน้า verify และใช้ OTP จากอีเมล Supabase ล่าสุด |
| ค้นหาอาหารไม่เจอ | ใช้เพิ่มเมนูอาหารด่วน แล้วส่งให้ Admin ตรวจ |
| Health Connect ไม่ซิงค์ | ตรวจ permission ใน Health Connect |
| หน้าเว็บยังแสดงชื่อ/ไอคอนเก่า | hard refresh หรือ clear site data/PWA cache |
| API ใช้งานไม่ได้ | ตรวจอินเทอร์เน็ต แล้วลองใหม่ หากยังไม่ได้แจ้งผู้ดูแลระบบ |

## 11. Checklist ทดสอบผู้ใช้ทั่วไป

ใช้ checklist นี้หลัง build/deploy:

- บันทึกกิจกรรมได้
- ค้นหาอาหารได้
- เพิ่มอาหารด่วนแล้วส่งให้ admin ได้
- เปิด AI chat ได้
